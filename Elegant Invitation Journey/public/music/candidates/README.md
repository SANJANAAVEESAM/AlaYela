Candidate tracks go here as 1.m4a, 2.m4a … 5.m4a.

Open the invitation with ?music on the end of the URL — for example
http://localhost:8080/?music — and a panel appears at the bottom letting you
switch between them while you scroll. "Current" plays the track that is live.
Any file that is not here is marked missing rather than failing silently.

Once chosen: rename the winner to ../invitation.m4a, delete this folder, and
remove MusicCandidates from Microsite.tsx.

Use only music you have a licence to publish — a wedding site is public.

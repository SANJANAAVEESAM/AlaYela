# Lasya & Avyay's wedding invitation

## Development

You need Node.js (or Bun) — [install Node with nvm](https://github.com/nvm-sh/nvm#installing-and-updating) or [install Bun](https://bun.sh).

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```
